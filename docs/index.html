全面进化的全栈架构

彻底剔除 Express，重塑为全栈 Bun + TypeScript 7.0+ 原生高性能体系，为 Web 播放与管理后台提供轻量可靠的底座。

原生 Bun.serve 零开销运行时

采用自研高性能洋葱模型路由与 Web 标准 Request/Response 抽象，告别繁重 Express 中间件封装，冷启动提速 500%，内存占用低至数十兆。

流畅的 Web 播放体验

原生音频播放、队列管理、歌词展示和媒体 Range 请求协同工作，桌面与移动端都能保持顺滑的播放控制。

聚合搜索与管理员音源

保留内置音源与后台管理员音源配置，支持搜索、解析、歌词和封面服务，浏览器同源 API 统一收敛。

bun:sqlite 原生持久化 (WAL 模式)

账户、会话、歌单快照与元数据全面升级至 SQLite 原生持久化，严苛外键约束与预写日志模式，降低数据损坏风险。

本地快照与数据恢复

管理后台提供本地快照、下载、上传和恢复能力，数据边界清晰，不依赖远程 WebDAV 服务。

生产级强密码与访问边界审计

启动时内置强制弱口令与示例密码拦截，杜绝公网空门；多租户数据路径硬隔离与防目录穿越校验，为家庭与私有云部署保驾护航。

开箱即用 · 容器化与本地运行双支持

多模式部署与本地运行指南

支持开箱即用的 Alpine Docker 容器化编排，或基于原生 Bun 运行时直接从源码毫秒级本地启动。

docker-compose.yml 
version: '3.8'

services:
  yun-yin:
    image: ghcr.io/biaobiaobiao108/yun-music:latest
    container_name: yun-yin
    user: "0:0"
    restart: always
    ports:
      - "9527:9527"
    volumes:
      - ./data:/server/data
      - ./cache:/server/cache
      - ./music:/server/music
      - ./cover_cache:/server/cover_cache
    environment:
      - NODE_ENV=production
      # 【必须设置】管理后台登录密码，禁止使用弱密码或 123456
      - FRONTEND_PASSWORD=YourStrongAdminPassword123!
终端单行命令 
docker run -d \
  --name yun-yin \
  --user 0:0 \
  --restart always \
  -p 9527:9527 \
  -v $(pwd)/data:/server/data \
  -v $(pwd)/cache:/server/cache \
  -v $(pwd)/music:/server/music \
  -v $(pwd)/cover_cache:/server/cover_cache \
  -e NODE_ENV=production \
  -e FRONTEND_PASSWORD=YourStrongAdminPassword123! \
  -e ENABLE_WEBPLAYER_AUTH=false \
  ghcr.io/biaobiaobiao108/yun-music:latest
终端直接运行（需安装 Bun） 
# 1. 克隆代码仓库并安装依赖
git clone https://github.com/biaobiaobiao108/yun-music.git
cd yun-music
bun install

# 2. 配置根目录 .env 文件 (Bun 原生自动加载)
cat < .env
FRONTEND_PASSWORD=YourStrongAdminPassword123!
PORT=9527
EOF

# 3. 极速编译前端产物（仅需数十毫秒）
bun run build:frontend

# 4. 启动服务（生产启动）
bun start

# 或使用热重载开发模式：
# bun run dev

核心环境变量速览

变量名 默认值 说明
FRONTEND_PASSWORD 必填 (空值退出) 管理后台管理员登录密码，严禁使用 123456 等示例弱口令
LX_USER_<name> 无 声明 Web 用户账户，例如 LX_USER_tom=pwd123
PORT 9527 服务监听端口
ENABLE_WEBPLAYER_AUTH false 是否强制 Web 网页播放器输入访问密码
