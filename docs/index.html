当前产品范围

项目仅提供浏览器 Web 播放器与管理后台。LX 客户端同步、WebSocket 同步、Subsonic / OpenSubsonic、WebDAV 和旧请求头 Token 接口均已移除。

从 Compose 开始，数据边界一目了然

设置管理员密码与初始账户后即可启动。播放器和管理后台通过同源 Cookie 会话访问。

Docker Compose

services:
  yun-yin:
    image: ghcr.io/biaobiaobiao108/yun-music:latest
    container_name: yun-yin
    restart: always
    ports:
      - "9527:9527"
    volumes:
      - ./data:/server/data
      - ./cache:/server/cache
      - ./music:/server/music
      - ./cover_cache:/server/cover_cache
    environment:
      NODE_ENV: production
      FRONTEND_PASSWORD: replace-with-a-strong-admin-password
      LX_USER_admin: replace-with-a-strong-user-password

数据各有去处

  • data/SQLite 数据库与实例配置
  • cache/可重新下载的播放缓存与歌词
  • music/用户下载的本地音乐，不受缓存 LRU 清理
  • cover_cache/封面缓存
启动命令 docker compose up -d

Compose 默认以 UID/GID 0:0 运行并丢弃 Linux capabilities。需要使用非 root 身份时，可设置 PUID / PGID，并确保挂载目录权限匹配。
